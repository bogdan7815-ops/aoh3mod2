================================================================================
NO COALITIONS MOD for Age of History 3
================================================================================

DESCRIPTION:
This mod removes coalition formation against players with high aggressive 
expansion. In the vanilla game, when you expand too aggressively, other 
nations will form coalitions against you. This mod disables that mechanic,
allowing you to conquer without facing coalition penalties.

FEATURES:
- Disables coalition formation for aggressive expansion
- Sets AI_EXTRA_AGGRESSIVENESS to maximum (100) for all governments
- Sets Coalition_AggressiveExpansion_Threshold to 999.0 (effectively disabled)

INSTALLATION:
1. Locate your Age of History 3 installation folder
2. Navigate to the "mods" directory
3. Copy the "NoCoalitionsMod" folder into the "mods" directory
4. Launch the game and enable the mod from the mod menu

FILES INCLUDED:
- mod.txt: Mod metadata for Steam Workshop
- game/Governments.json: Modified government settings
- game/GameValues.json: Modified game values for coalition threshold
- logo.png: Mod icon (placeholder - replace with your own image)
- README.txt: This file

COMPATIBILITY:
- Should be compatible with most mods that don't modify Governments.json
- Load order: Place this mod after any scenario or map mods

NOTES:
- The logo.png file is a placeholder. Replace it with a 512x512 PNG image
  before publishing to Steam Workshop.
- This mod affects gameplay balance by removing a natural check on expansion

VERSION: 1.0
AUTHOR: Created for Age of History 3 community
================================================================================
